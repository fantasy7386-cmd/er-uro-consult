操作說明

簡介

本工具將 120+ 筆真實泌尿科急診照會整理為 19 個診斷類別、41 條處置路徑，幫助你快速找到適合的英文照會回覆範本。

步驟一：搜尋或選擇診斷

在搜尋欄輸入關鍵字（如 "hematuria"、"stone"、"torsion"），或點擊下方快捷按鈕。左欄會篩選出對應的診斷類別。

步驟二：選擇處置路徑

點選左欄的診斷後，中欄會顯示該診斷的處置選項（如 "Surgery"、"Conservative"、"MET + OPD"）。每條路徑代表不同的臨床情境。

步驟三：複製範本

點選處置路徑後，右欄顯示英文照會範本。你可以：

  • 直接編輯文字內容
  • 點 Copy All 一鍵複製
  • 點 Reset 可回復原始範本

特殊功能：TWIST Score 計算器

選擇「Testicular Torsion / Pain」→ 點選 Assessment 欄 → 點 TWIST Calc 按鈕，互動勾選計算分數。Assessment 區域可直接編輯，點 Copy 複製、Reset 回復原始範本。

鍵盤快捷鍵

  • / 聚焦搜尋欄
  • Esc 清空搜尋 / 關閉視窗
  • ↑ ↓ 切換診斷或處置路徑
  • ⌘/Ctrl + Enter 複製目前範本

離線使用 (PWA)

本工具支援 PWA — 第一次載入後即可離線使用。手機可在 Safari 點「分享 → 加入主畫面」、Chrome 可點「安裝應用程式」，加到主畫面後支援全螢幕、離線、開機快速啟動。

「最近使用」自動置頂

常用的診斷類別會自動排在前面（依使用次數），有 ★ 號代表使用 ≥3 次。資料只存在你自己的瀏覽器，不會上傳。

淺色 / 深色模式

右上 A / ☀ / ☾ 按鈕循環切換主題：A 跟隨系統 → ☀ 強制淺色 → ☾ 強制深色。設定會記在這個瀏覽器裡。

列印

瀏覽器 ⌘/Ctrl + P 可只列印目前 Template 內容（自動隱藏其他欄位）。

小提示

  • 可輸入多個關鍵字（如 "stone infection"），會以 AND 條件篩選
  • 所有範本皆源自真實照會紀錄，非 AI 生成內容
